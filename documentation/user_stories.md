# CodeForge Platform - User Stories & Acceptance Criteria

| ID | User Role | Wants To | So That | Acceptance Criteria |
|---|---|---|---|---|
| US001 | User | Register using email | Access platform securely | Email validated, password hashed, JWT issued |
| US002 | User | Login to account | Solve problems | Token verification, session persisted |
| US003 | User | Submit code | Receive automated verdict | Submits to Judge0, returns AC/WA/TLE/MLE/CE |
| US004 | User | View submission history | Track improvement | History table with runtime, memory and date |
| US005 | User | View leaderboard | Compare ranking | Ranked by score, problems solved, streak |
| US006 | Problem Setter | Create problems | Add challenges | Supports constraints, visible & hidden test cases |
| US007 | Admin | Manage users | Maintain system integrity | Ability to promote, demote, or suspend accounts |
| US008 | Moderator | Remove comments | Maintain discussion quality | Soft delete abusive comments and flag posts |
| US009 | User | Search and filter problems | Find relevant questions | Filter by tag, difficulty and status |
| US010 | User | Earn badges | Stay motivated | Badges awarded on problem count milestones |
